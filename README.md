# Resume Analyzer

An AI-powered Resume Analyzer that helps users evaluate resumes for ATS compatibility, extract important skills, analyze resume quality, and receive smart improvement suggestions for better job opportunities.

---

## Features

- ATS Resume Analysis
- Skill Extraction
- Resume Scoring
- Smart Suggestions
- PDF/DOCX Upload Support
- Responsive UI

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript, React
- Backend: Node.js, Express.js
- Database: MongoDB
- AI/NLP Tools
